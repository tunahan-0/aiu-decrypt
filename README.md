# AIU Decrypt

Bu aracı kullanarak 'spesifik bir algoritmayla' şifrelenmiş dosyaların şifresini çözüp içeriğini çıkarabilirsiniz. Yani herhangi bir şifreli dosyayı çözemez, sabit bir çözme algoritması kullanır.

## Kurulum

- Releases sekmesinden .exe dosyası olarak indirebilirsiniz. 
- Dilerseniz `gui.py`, `decrypter.py` ve `requirements.txt` dosyalarını indirip hepsini aynı klasöre attıktan sonra `pip install -r requirements.txt` komutuyla gerekli kütüphaneleri kurabilir ve direkt `gui.py` dosyasını çalıştırıp kullanabilirsiniz.

## Kullanım

Kullanıcı arayüzünden dosyayı seçip hedef dizini göstermeniz yeterli. Gerekiyorsa 'Ayarlar' menüsünden ffmpeg dizini de tanımlayabilirsiniz. Uygulama hedef dizinini ve ffmpeg dizinini hatırlar, her kullanımda sadece dosyayı seçmeniz gerekir.
